# UD5. Detección y documentación de incidentes de ciberseguridad

> La solución técnica no es suficiente si no se comunica bien y no queda constancia del incidente. La documentación y la notificación forman parte esencial del proceso de respuesta.

## 1. Resultado de aprendizaje

Detecta y documenta incidentes de ciberseguridad siguiendo procedimientos de actuación establecidos.

### Criterios

- Desarrolla procedimientos de notificación.
- Notifica internamente los incidentes.
- Notifica a las personas o entidades adecuadas.

## 2. Fases de la notificación

1. Detección del evento.
2. Validación del incidente.
3. Comunicación interna.
4. Comunicación externa si procede.
5. Documentación y cierre.

## 3. Qué debe documentarse

- hechos sucedidos,
- sistemas afectados,
- datos o activos implicados,
- evidencia disponible,
- medidas adoptadas,
- responsables,
- impacto,
- lecciones aprendidas.

## 4. Comunicación interna y externa

La notificación no debe ser improvisada. Debe seguir un protocolo y definir:

- prioridad,
- canal de comunicación,
- destinatario,
- nivel de detalle,
- tiempo de respuesta.

## 5. Ejemplo de notificación

```text
Incidente detectado en sistema de gestión de usuarios.
Se confirma acceso sospechoso desde IP no autorizada.
Se han bloqueado accesos y se está validando impacto.
Se comunica a dirección y seguridad para activar protocolo.
```

## 6. Resumen

La detección y la documentación convierten los incidentes en experiencia útil para la organización, evitando que se repitan y permitiendo una respuesta más sólida en el futuro.
